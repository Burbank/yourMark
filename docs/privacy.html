yourMark

Privacy

yourMark converts files on your computer. We do not run a yourMark account, and we do not receive your PDFs.

Files

Conversion happens on this Mac (or in this browser tab for the preview). Markdown is written where you choose. Keep the original file.

Ask

Ask is optional. If you paste an API key, it stays on this computer. It is sent only when you ask a question, and only to the provider you pick (xAI, OpenAI, or a URL you type). yourMark does not keep a copy of the key on a server.

Translate

Translate is optional. When you press Translate, the open chapter is sent to Google Translate or to the Ask provider you already use — whichever you pick in Settings. The key stays on this computer. Convert still happens on this Mac.

Updates

The GitHub Mac app may check GitHub for a newer yourMark and PyPI for a newer Microsoft MarkItDown. The App Store build does not — updates come from Apple.

Crash reports

If the app closes unexpectedly, it can copy a macOS report. Nothing is sent unless you choose. API keys and document text are not included.

This website

The browser preview at burbank.github.io/yourMark keeps files in this tab. It does not upload them.

Questions: open an issue on GitHub.
