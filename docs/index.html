Mac app

yyourMark

Turn a PDF into Markdown you can search, bookmark, and ask. Conversion stays on this Mac. Microsoft MarkItDown does the heavy lifting — yourMark is the window.

Download for Mac Source

For everyone (no Terminal)

  1. Download the disk image.
  2. Drag yourMark into Applications.
  3. Double-click Install Engine on that same disk image (installs MarkItDown once).
  4. Open yourMark. If macOS asks, System Settings → Privacy & Security → Open Anyway.

Homebrew (optional)

Not required. Handy if you already use brew:

brew tap Burbank/yourMark
brew install --cask yourmark
uv tool install 'markitdown[all]'

Terminal

curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install 'markitdown[all]'
git clone https://github.com/Burbank/yourMark.git
cd yourMark && ./Scripts/Install.command

What you get

Tables stay tables. Pictures sit in reading order. The outline is the PDF’s bookmarks. Ask a chapter — answers come from the file. Keep the original PDF.
